# TypeScript and code style

- Write TypeScript and React components; strict type checking is enabled in `tsconfig.json`.
- Follow the existing Prettier and ESLint configuration. Use two spaces for indentation and let the configured plugins organize imports and Tailwind classes.
- Use PascalCase for components and types; use camelCase for functions, hooks (`useSomething`), and variables.
- Use descriptive route and file names consistent with nearby code.
- Use the `@/` aliases defined in `tsconfig.json` for shared modules.
